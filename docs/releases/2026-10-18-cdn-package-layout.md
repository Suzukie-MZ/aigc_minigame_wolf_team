# CDN 动画与客户端发行目录

本次按已确认的 CDN 包体方案接续 OMW 的 cdn-combat-animation-config：攻击动作、英雄四方向、攻击/产金特效从配置中的 CDN 图集按需加载。源码目录保留本地 combat 图集和生成元数据供开发与测试，发行入口不加载这些元数据，也不再声明 combat 分包。缺少或无效 CDN 动画时保留静态角色与基础表现，不下载被排除的本地 combat 分包。

## 构建与上传

需要 Python 3 与 Pillow（本地验证 Pillow 11.3.0）。执行：

```sh
python3 scripts/build-game-package.py --output /tmp/wolves-release.zip
```

生成 `/tmp/wolves-release/` 独立发行目录、ZIP、同名 `.size.json` 大小报告。**开发者工具导入/上传发行目录，勿直接上传 Git 源码目录**。ZIP 与发行目录内的运行文件逐字节相同，目录中仅额外包含所有权标记 `.runtime-stage.json`。构建仅覆盖自身生成过的目录，拒绝覆盖源码、父目录或未标记目录。

构建保留启动/UI 图片及现有怪物动画分包，排除开发用途的 combat 图集、未接入的 terrain-depth，以及文档、测试、Git 数据。检查静态脚本/图片引用后，对发行目录 PNG 做无损压缩：仅删除全不透明图片的冗余透明通道及优化压缩编码，每张图均验证尺寸和解码后的 RGBA 像素完全一致。源图片不改动。

预算检查依据真实发行文件：主包及每个分包不超过 6,000,000 字节；总量不超过 30,000,000 字节。测试实际构建 ZIP，重算目录体积并验证 ZIP 条目与目录内容一致。新增素材或拉取代码后必须重新构建，不沿用历史大小结论。

## 本次验证快照（合并上游前）

- 主包 4,868,341 字节；最大分包 battle-images 5,642,680 字节。
- 全部运行文件 29,953,186 字节；ZIP 29,362,718 字节。
- 已排除约 22 MB 开发 combat 图集；怪物/UI 资源保留兼容。
- 总量余量约 46 KB，后续继续添加图片前需要进一步迁移 CDN。
- CDN/动画与包体专项测试 24 项通过；客户端全量测试 75 项通过。

这是构建验证，不代表小游戏平台已经上传或发版。客户端需使用更新后的发行包才能读取新版战斗动画配置。
