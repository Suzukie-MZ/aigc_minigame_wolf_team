# 对局UI：无内框战场与紧凑部署区

## 当前实现

保留原关卡矩阵、路线、可部署格、0.72纵向投影、单位朝向与战斗特效。移除围住棋盘的内层装甲箱及上下灰色隔离带，战场使用可用宽度减16px；414px基准下实际矩阵最大宽度398px，上一版382px。地图全量显示，不启用缩放、拖动或裁切。

原8×6矩阵在2.5D投影后比样例的方形地图更扁，等比缩放不能同时填满竖向空间。因此场景区域用同源地面连续延伸到外侧工业墙，少量环境矿石放在矩阵之外。延伸区域只作环境，不新增可部署格，点击仍用原矩阵逆投影校验，边缘不会误部署。整体战场区域自顶部HUD下方延伸到部署面板上方，占据主要面积。

## 部署区

英雄行102px，塔卡118–140px（随屏高适配）。英雄卡缩窄到268px（414px基准），右侧暂停/支援各98×48px，左右18px内距相等。英雄上半身取图与独立边框保留，名称、角色、费用沿同一左边线紧凑排列。塔图等比例按透明边界取图，名称紧接图像，价格位于名称下方。卡片使用选英雄页连续装甲边框，选中为琥珀色。

暂停按钮为青色实底和深色暂停符号，暂停后的继续按钮改用播放三角。支援按钮为紫色实底、独立问号与浅紫文字，图标与文字组成居中组。文字宽度包含实际字体advance与字间距，避免两个汉字出现省略号。

## 顶部状态

三组图标更新为分层金币、骷髅波次、轮廓盾牌。图标32px，小屏26px；标签14px、小屏12px；数字22px、小屏18px。三个数字使用相同y和高度，沿用高清粗体字体。价格金币也沿用同一图标家族。

## 验证

63项检查通过，涵盖414×896、390×844安全区、320×568短屏，8×6、16×16、30×40矩阵，首尾格点击、装饰区域拒绝部署、左右内距、卡片间隔、触控尺寸、无内框布局、实时字形测量不截断，以及2.5D朝向、敌人动画、战斗流程和WebGL有限几何。合并前发布检查发现：当前运行资源14,034,064字节，超过构建脚本6,000,000字节总量阈值；远程基线已包含9,399,171字节怪物分包。本次保留现有预算规则，不进行发布部署。实机截图：battle-ui-compact-preview.png。
