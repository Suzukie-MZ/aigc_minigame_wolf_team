# 选英雄弹窗实现

依据用户指定的《启元传说美术与 UI 设计风格规范》、ui规范板.webp、选英雄.webp。

- 92% 宽度的居中装甲弹窗，覆盖真实选图页面，遮罩 66%。
- 三行单选档案卡；青色未选边框、琥珀选中边框与圆形勾选；取消/关闭返回选图，下一步进入防御塔选择；此阶段不扣体力。
- 英雄图片始终使用配置中的 portraitAsset，只在 WebGL UV 取样时按比例截取半身。配置与源图不变。
- 名称 18px、角色标签 12px、实际等级 14px；正文使用同一高清字库。未选英雄时下一步禁用。
- 414×896、390×844、320×568 布局回归，主要按钮与关闭热区至少 48px。

运行时只取独立边框、静态标题、标签框和按钮，名称、等级、角色和选择状态实时绘制；生成图中的背景与空白人物占位不作为页面贴图。

为保持上传预算，打包器只排除已经由 ui-icons.png 替代的 14 个原始图标；源文件保留在项目内。TextureAssets 对同名 UI 图标统一采用本地图集，含远程配置同名项。自动测试验证取样区域和请求地址。
