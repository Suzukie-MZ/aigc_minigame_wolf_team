# 选图页参考实现与差异

参考：用户提供的 `ui设计参考/选图.webp`，286 × 618。布局坐标按页面宽度缩放，414 × 896 为游戏基准。

## 独立组件与实际功能

- 标题、品牌牌匾、导航图标：参考图对应区域作为独立 UI 装饰绘制。顶部图标均有独立点击区域。
- 金属面板与卡片：只取边缘、角点，使用九宫格拉伸；中心由代码填充。
- 进入按钮：只取按钮边缘；文案、启用状态及点击由代码控制。
- 关卡缩略图：逐格读取实际 `level.map.tiles`。地面和道路使用独立的 16px 像素材质图集，障碍、入口和终点使用独立材质区域；不使用参考图的完整地图缩略图。支持城市、工业、荒地和森林材质，优先读取地图主题；主题未命名时按关卡名称选择预览材质，仅影响列表表现。
- 全部关卡、关卡总数、关卡编号、名称、解锁标记、锁图标、解锁提示：由实际关卡配置和存档绘制。
- 底部四个入口：独立图标，数值从实际系统配置和存档读取。体力不固定为参考图中的 6。
- 原有 H5 调试胶囊已隐藏，避免叠加在真正的导航控件上。

| 控件 | 行为 |
| --- | --- |
| 首页 | 返回关卡列表第一屏，停止滚动惯性 |
| 更多 | 打开作战终端，进入玩法说明或关闭 |
| 关闭 | 退出确认；快手调用 `KwaiBase.exit`，浏览器结束本次预览并提供重新进入 |
| 关卡卡片／进入关卡 | 校验解锁状态后进入真实关卡详情；锁定关卡说明原因 |
| 看广告 | 调用实际激励广告接口，仅完整观看成功后发放配置中的体力 |
| 分享 | 调用实际快手分享接口，仅成功回调后发放配置中的体力 |
| 体力 | 展示当前体力、上限及补充方式 |
| 英雄强化 | 进入原有英雄强化界面，使用实际材料与等级判断 |

弹窗会拦截背景点击、拖动和滚轮；取消广告或分享不发奖励。浏览器不模拟平台奖励，会明确提示需在快手环境使用。

## 无法逐像素相同的部分

1. 参考图前两关可挑战，当前新存档只解锁第一关；必须随真实通关记录变化。
2. 参考图体力为 6，当前数值由存档、每日恢复和实际消费决定。
3. 参考图前几个名称为“青云山门、落霞小径、废墟前哨、边境工厂”，当前服务器下发的是另一套关卡名称与路线。界面继续使用真实关卡，避免显示内容与进入关卡不一致。
4. 参考没有独立地图精灵、字体源文件或可编辑组件。静态装饰按参考图高清修复，动态文字使用黑体加粗高清字库，笔画不会与生成图完全相同。
5. 装饰图已修复到 853 × 1844，高清字体图集为 1280 × 1472，浏览器画布至少使用 2 倍像素密度。修复能改善边缘，但无法还原原图中不存在的真实细节。
6. 快手原生系统胶囊、分享面板、广告和退出行为由宿主控制，浏览器预览不能完整复现；需在快手环境验证真实 SDK 流程。

## 验证

- 自动化覆盖双列点击、末行滚动、固定底栏、首页／更多／玩法／体力／强化入口、弹窗拦截、SDK 成功和取消回调、退出确认。
- 地图与按钮由代码绘制和命中检测，未使用整页截图覆盖游戏界面。
- 关卡编号与名称共用固定文字行；状态框、按钮与底栏均按真实字宽和共同基线居中，不压缩字形。奖励数字使用更小的金属角标。

## 规范复核后的修复（2026-10-16）

- 编号字号 18，编号框按“第30关”的真实字宽分配；关卡名称字号 14，在小屏自动均衡换行，不挤压字形。名称与编号共用可见笔画中心，横线位于同一中心线上。
- 状态、解锁说明、资源角标字号提高到 12；底栏标签 16。高清字体补齐验证用关卡名称，共 531 个字形（含防御塔名称）。
- 首页、更多、关闭使用独立的 48 × 48 点击区域，互不重叠；标题随顶部操作区下移。图标保持正常比例。
- 底栏避让原生底部安全区，缩略图保持真实格子的正方形比例；建造格和英雄格分别保留绿色、青色标记。
- 新像素材质由 `scripts/build-map-terrain-atlas.py` 确定性生成，128 × 64 图集内每格为 16 × 16。使用有限色阶、固定像素簇和独立道路，避免为每个像素反复提交 WebGL 绘制。
- 封面保持 853 × 1844，从高清 PNG 原稿直接输出 WebP 质量 80，298,558 字节；相较之前质量 50 的 JPEG，RGB 压缩误差更低。插画构图不变，加载文字和百分比按同一中心线绘制。
- 自动化验证编号 1–30、关卡名称、三种屏幕宽度、触控范围、底部安全区、主题选择和原有交互。浏览器实际检查 320 × 568 的首屏与末尾编号，并确认正常入口从封面自动进入列表。快手 SDK 和真机安全区仍需宿主验收。
