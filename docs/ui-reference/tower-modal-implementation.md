# 防御塔选择弹窗

依据：`ui设计参考/选防御塔.webp`、`启元传说美术与UI设计风格规范.md` 第 8、9 节，以及规范板。

- 92% 宽度的深蓝战术终端弹窗，背景为不可操作、变暗的真实选图列表；两列三行展示六种可用塔。
- 标题 28，塔名 18，说明 12，费用 14，主要按钮 18；文字与数值实时绘制，不使用整页贴图。
- 钢灰金属边、青色辅助信息、琥珀选中描边与勾选；未选四座时开始按钮不可用。上一步、开始和关闭的点击区域不小于 48px。
- 名称、图像、用途和费用来自实际卡牌及当前关卡单位配置。图像等比放入蓝图区，费用在各卡相同位置显示。
- 流程对齐规范：关卡简报 → 单选英雄（1/2）→ 防御塔选择（2/2）→ 开始战斗。上一步保留选择，回到塔选择也保留已有阵容；关闭回到地图，新建出战准备时清空上次选择。
- 最多选择配置要求的四座塔，再次点击取消选择。开战同时验证英雄、阵容和体力，确认成功才消费体力，之后使用真实英雄及阵容创建战斗。
- 小屏仍显示六张卡及操作区；保留顶部、底部安全区域。移除了逐帧清空底部安全区的旧代码。

## 与参考的差异

用户确认：塔图必须使用游戏配置提供的独立素材，不要求塔造型与参考图相同；除此之外的 UI 按参考样式制作。`card.portraitAsset`、名称、费用、攻击范围和升级规则保持由游戏配置控制，不覆盖为新生成的塔模型。
